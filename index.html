What to look for in TORGO

For LR and MLP, supportive deletion lowers mean target-class accuracy as the deletion fraction increases, while counteracting deletion generally preserves or improves it. Whisper-based CNN curves are less regular. Inspect the individual classes to see which groups drive each average.

Behind the curves

One ranking. Three deletion strategies.

For each target test class, average training-sample influence over test utterances from that class. Rank the full training set using these scores, then compare equally sized deletions.

01 / Supportive

Remove the most positive

Delete training utterances with the highest influence scores for the target class.

Expected patternLower target-class accuracy than random deletion.

02 / Counteracting

Remove the most negative

Delete training utterances with the lowest influence scores for the target class.

Expected patternTarget-class accuracy may improve when counteracting evidence is removed.

A note on averaging

Class average ≠ overall accuracy

For a fixed dataset, representation, classifier, gradient scope, deletion strategy and fraction, let Ac be the accuracy on target class c after its own deletion-and-retraining experiment. The displayed class average is:

Mean target accuracy = (1/K) ∑c=1K Ac

Here K = 4 for TORGO and K = 5 for UASpeech. Different target classes can select different training utterances for deletion, so the average combines results from different retrained models.

Interpretation notes & limits +
  • Compare the three strategies within the same configuration and deletion fraction. Curves need not be monotonic, and counteracting deletion need not improve every class.
  • Class-wise panels use different vertical ranges. Compare numerical accuracy values rather than visual slope alone.
  • “Full” uses full-model gradients; “Last layer” uses final-layer gradients. LR has only one trainable classification layer, so these scopes coincide.
  • Class names and numeric IDs are retained exactly as shown in the supplied figures. TORGO's original class IDs are not an increasing severity scale; use the named labels when interpreting them.
  • Influence is computed using reference labels. These experiments test the model's dependence on training data for those labels, rather than directly explaining an incorrect predicted label.
  • The curves describe the supplied experimental partitions. They do not by themselves establish clinical utility or generalisation to unseen speakers.
